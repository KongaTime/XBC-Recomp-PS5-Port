# Controls and graphics

[Back to the project](../README.md)

## Launcher controls

| Input | Action |
| --- | --- |
| D-pad / left stick | Navigate |
| Cross | Activate the selected button or setting |
| Left / Right | Change the selected graphics value |
| Circle in Settings | Discard the unsaved draft and return |
| Square in Settings | Restore the 1080p / 60 FPS graphics defaults |
| Save changes and return | Save the draft for the next Play launch |

Changes apply when the game starts from the launcher. Square changes the draft; choose **Save changes and return** to keep it.

## Game mapping

| Game action / Switch input | DualSense |
| --- | --- |
| Confirm / A | Cross |
| Back / B | Circle |
| X | Triangle |
| Y | Square |
| Plus | Options |
| Minus / Select | Touchpad press |
| L / R | L1 / R1 |
| ZL / ZR | L2 / R2 |
| Left / right stick click | L3 / R3 |

The package configuration explicitly swaps A/B for Cross-confirm and Circle-back. PlayStation prompts follow the configured bindings. The touchpad binding has been saved; a dedicated physical-controller check after relaunch is still pending.

## Graphics settings

| Setting | Options |
| --- | --- |
| Internal resolution | Match game, 720p, 1080p, 1440p, 2160p, percentage scales and Dynamic |
| Upscaler | Bilinear or AMD FSR 1 |
| Anti-aliasing | Off or SMAA |
| Depth of field | On / Off |
| Game AA / motion blur | On / Off |
| Frame-rate target | 30, 60, 120, 144, 165 or Unlimited |
| V-Sync | On / Off |
| Cutscene frame rate | Same as gameplay or steady 30 |
| FPS counter | On / Off |

Available settings are not performance guarantees. Dynamic and high frame-rate choices inherit runtime behavior and have not all been validated across the game.

The default package targets **1920×1080 internal rendering and 60 FPS**. Tested display output is 3840×2160. Original texture images are retained; increasing internal resolution does not install higher-resolution textures.

Pre-rendered movies retain their source detail and frame rate. The tested opening movie is 1280×720 at 30 FPS.

FSR 3, DLSS and frame generation are unavailable in this PS5 build. The native launcher's Graphics page replaces the desktop settings overlay.
